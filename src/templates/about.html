About This Application

This is a Python Flask application with Bootstrap 5 integration.

Features

  • Flask web framework for backend routing
  • Bootstrap 5 for responsive design
  • Jinja2 templating engine
  • Base template with navigation and footer
  • Default routes (Home and About)
Technology Stack
  • 🐍 Python
  • 🌶️ Flask
  • 🎨 Bootstrap 5
  • 📄 Jinja2

Getting Started

To run this application, install the dependencies with pip install -r requirements.txt and run python app.py.
